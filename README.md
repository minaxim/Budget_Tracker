
# Budget Tracker

## Project Overview
A simple Budget Tracker project developed using Python and Pandas.

## Objectives
- Load budget spending data.
- Display expense records.
- Calculate total expenditure.
- Calculate department-wise spending.
- Filter expenses.
- Generate a CSV report.

## Technologies Used
- Python
- Pandas
- Google Colab
- GitHub

## Dataset
Budget Spending Dataset obtained from Kaggle.

## How to Run
1. Download the repository.
2. Open Budget_Tracker.ipynb in Google Colab.
3. Upload the required CSV dataset.
4. Run the notebook cells.
